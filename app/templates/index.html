ℹ️ About the System

  • Uses the official CBC formula: Final = (Formative × 20%) + (Summative × 80%)
  • Assigns grades A–E with official UNEB/NCDC descriptors
  • Generates professional one-page PDF report cards ready for printing
  • Produces a class summary for quick overview
  • Works for S1–S4 (Lower Secondary / UCE)
